# PSXFunkin Omniplasm Engine
i dub thee: "The PS3 Cell chip of PSXFunkin engines!" due to it's advanced features and limited "how-to-do's" this engine is only recommended for folks that want to make a PSXFunkin port as close to the original mod as possible. this engine currently features:

    * Longer Song Support
    * Extra Keys
    * Lyric Cutscenes Video And Event Code
    * Advanced Character/Stage Drawing Features
    * Amongst Other Features I Forgot About
